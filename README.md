## 🌍 About Dorios Studios

[Dorios Studios](https://github.com/DoriosStudios) builds and maintains the ecosystem this addon runs on:

- **UtilityCraft** — the shared engine for energy, fluid pipes, machine IO, and item transport
- **DoriosLib** — the internal scripting library powering all Dorios Studios projects
- **DE (Dorios Energy)** — the shared power unit compatible across all addons

All Dorios Studios addons are designed to work together — Advanced Chemistry plugs straight into the same ecosystem.

---

## 🚀 Installation

1. Install **UtilityCraft `3.6.0+`** first — Advanced Chemistry requires it
2. Double-click `Advance_chemistry.mcaddon` — Minecraft imports it automatically
3. In your world settings, enable **both** packs:
   - ✅ Behavior Pack
   - ✅ Resource Pack
4. Launch the world and start the chain
