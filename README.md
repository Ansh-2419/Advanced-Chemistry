# ⚗️ Advance Chemistry

**The fuel processing chain Minecraft was always missing.**

A UtilityCraft expansion. Built for SkyBlock.

Vanilla Minecraft has furnaces and lava. We wanted refineries, cracking towers, and hydrocarbons — a real industrial fuel chain where every fluid has a purpose and every machine earns its place.

</div>

---

## The Idea

Real-world fuel production starts with something organic — crops, biomass, raw hydrocarbons — and refines it through a chain of chemical processes into something useful. That chain doesn't exist in Minecraft.

Advance Chemistry adds it. Press seeds into oil. Ferment sugarcane into ethanol. React biofuel into hydrocarbon slurry, crack that into crude oil, run it through a multiblock refinery, and walk away with diesel, petrol, and naphtha. Each fluid is a step in a real process. Nothing is a dead end.

---

## Built for SkyBlock

Advance Chemistry was designed with SkyBlock and OneBlock worlds in mind. Every input in the fuel chain comes from farmable, renewable sources — seeds, sugarcane, crops. No ore dependencies to gate progression. The Greenhouse multiblock automates the farming side so the whole chain can run without touching the ground.

If you're building a SkyBlock pack and want a deep tech progression that doesn't rely on the overworld, this is it.

## Machines

Fermenter · Fuel Mixer · Chemical Reactor · Separator · Polymerizer · Industrial Crusher · Nuclear Processor · Relic Synthesizer · and more.

Each one is a step in the chain — inputs go in, fluids come out, and the next machine takes over.

We also have a lot of multiblock structures. Refinery, Fuel Burner, Fluid Storage, Greenhouse — all built from casings, ports, and monitors. If you like building big, there's plenty here.

## The Fluid Chain

```
Crops / Seeds
    └── Fermenter ──────────► Ethanol · Plant Oil
                                    │
                               Fuel Mixer ──────► Biofuel
                                                     │
                                            Chemical Reactor ──► Hydrocarbon Slurry
                                                                         │
                                                                    Separator
                                                                   ┌─────┴─────┐
                                                          Heavy Hydrocarbon   Reactive Fluid
                                                                   │
                                                          Chemical Reactor ──► Crude Oil
                                                                                   │
                                                                       Refinery (Multiblock)
                                                                      ┌──────┬──────┬──────┐
                                                                   Diesel  Petrol  Naphtha  →  Plastic Resin
```

Every fluid feeds the next step. Nothing is a crafting dead end.
